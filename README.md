# Amazon-Sales-Project
Exploratory Data Analysis of Amazon product data: discounts, pricing, ratings, and sales patterns.

# Overview  
This project explores Amazon’s product dataset to uncover insights about **pricing strategies, discounts, categories, and customer ratings**.  
The analysis focuses on understanding how discounts influence sales, what drives customer satisfaction, and where growth opportunities lie.  

# Tools & Libraries  
- Python (pandas, numpy)  
- Visualization (matplotlib, seaborn)  
- Jupyter Notebook  
- PowerPoint (for presentation of insights)

# Project Structure  
- `Amazon_Analysis.ipynb` → Full notebook with data cleaning, analysis, and visualizations  
- `Amazon_Analysis_Presentation.pdf` → Slide deck summarizing key findings & recommendations

# Key Insights  
- Discounts strongly influence customer purchasing behavior  
- Ratings and reviews build trust and affect satisfaction  
- Opportunities exist in underrepresented but growing categories  

# Recommendations  
1. Optimize discounting strategies by focusing on high-demand/competitive categories  
2. Explore category expansion to capture emerging demand  
3. Strengthen customer trust by improving product ratings and review quality
